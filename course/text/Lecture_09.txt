The ATM Problem




     Transaction times at the bank have mean 270 seconds and standard deviation 24 seconds.
             An ATM is installed to reduce them. A sample of 38 transactions is taken.
      How can the sample mean be used to test the claim that the true population mean transaction time is now less
         than 270 seconds? The number 270 is known, the new mean is not, and the only evidence available is 38
        observations. Every element of the machinery built in this part exists to turn that evidence into a decision.
TESTS FOR μ WHEN n IS LARGE


Formulation of H₀ and H₁


      When the goal is to establish an assertion, the NEGATION of that assertion is taken as H₀,
                                and the assertion itself is taken as H₁.
    H₀ represents the default position: no difference exists between the groups or quantities compared. H₁ proposes
   that a difference does exist. For the ATM problem, H₀: μ = 270 against H₁: μ < 270. The original question — is there
      strong evidence for the claim? — is thereby translated into a question that can be answered: is there strong
                                                evidence for rejecting H₀?




         H₀ always carries an equality, because only a definite number makes a distribution computable.

Locating the Critical Value
α fixes c, and c fixes the rejection region




  THE ATM PROBLEM
  Choose c so that P( x̄ ≤ c ) = α when H₀ holds
  Under H₀ the sample mean is approximately N(270,
  24/√38). Standardising gives Z = (x̄ − 270)/(24/√38), and
  P(Z ≤ −1.645) = 0.05.
  • 24/√38 = 3.89 seconds — the standard error
  • c = 270 − 1.645 × 3.89 = 263.60 seconds
  • R : x̄ ≤ 263.60, equivalently R : Z ≤ −1.645

A Worked Case: Testing a New Drug
H₀: the drug has no effect, and behaves like a placebo. H₁: the drug has an effect.




  IF H₀ IS REJECTED
  The conclusion is that the drug works. If H₀ was in fact true, this is a Type I error: a useless drug is adopted, and
  patients are treated with it.



  IF H₀ IS RETAINED
  The conclusion is that the drug does not work. If H₁ was in fact true, this is a Type II error: a genuinely effective
  drug is abandoned.

α and β




     α = P( reject H₀ | H₀ is true ) — the level of significance. β = P( fail to reject H₀ | H₁ is true ).
   For the ATM problem these read as α = P( x̄ ≤ c when μ = 270 ) and β = P( x̄ > c when μ < 270 ). False rejection of H₀
    is ordinarily treated as the more serious of the two, which is why the threshold is placed where it is: a decision to
   reject H₀ must rest on strong evidence. α is chosen by the analyst; β is not chosen, and follows from α, from n, and
                                              from the true size of the effect.

The Trade-Off Between the Two Errors




  No choice of the cutoff c minimises both α and β. Moving c to make α smaller makes β larger,
                                        and the reverse.
   The cutoff is a single number on a single axis, and the two error probabilities are measured on opposite sides of it.
    Practice therefore fixes α at a conventionally small value — 0.10, 0.05 or 0.01 — and accepts whatever β follows.
  The only way to reduce both at once is to increase n, which narrows both distributions and is the reason sample size
                                                     is worth paying for.

Example: Testing the ATM Claim
n = 38 · sample mean 261 seconds · sample standard deviation 22 seconds

  −1.96

  • −2.52 < −1.96, so H₀ is rejected
  • The claim of a reduction in mean transaction time is strongly supported

A Worked p-value: A Headache Drug
H₀: the new drug relieves pain no better than the old one. H₁: the new drug is better.




   The trial returns p = 0.03. At α = 0.05, since 0.03 < 0.05, H₀ is rejected: there is evidence that
                                  the new drug relieves pain better.
  Read the number carefully. p = 0.03 states that IF the two drugs were equally effective, a difference at least as large
    as the one observed would appear in about 3 trials out of 100. Because that is unlikely, the assumption of equal
           effectiveness is doubted. The figure 0.03 is not the probability that the drugs are equally effective.

How Strong Is the Rejection in the ATM Test?
The smallest α at which H₀ would still be rejected




  FROM Z = −2.52
  P( Z ≤ −2.52 ) = 0.0059
  This significance probability is the p-value of the
  observed z. Compared with α = 0.025 it is far smaller, so
  H₀ is not merely rejected: it is rejected decisively, and
  the result is highly significant.
  • H₁: μ < μ₀ is a left-sided alternative — R : Z ≤ −z(α)
  • H₁: μ > μ₀ is a right-sided alternative — R : Z ≥ z(α)
  • H₁: μ ≠ μ₀ is two-sided — both tails, each of size α/2

Example: Bacteria Count at a Lake Beach




      A city health department wishes to determine whether the mean bacteria count per unit
      volume of water is within the safety level of 200. Ten unit-volume samples are collected.
    The counts are 175, 190, 215, 198, 184, 207, 210, 193, 196 and 180. Do the data strongly indicate that there is no
   cause for concern? Ten observations is far below the threshold at which the central limit theorem can be relied on,
                             so this is a small-sample problem and the t distribution applies.
TESTS FOR μ WHEN n IS SMALL


The Bacteria Count Test
H₀ : μ = 200 versus H₁ : μ < 200 · α = 0.01 · left-sided




  T = ( X̄ − 200 ) / ( S/√10 )
  With df = 9, the rejection region is R : T ≤
  −2.821
  From the ten measurements, x̄ = 194.8 and s = 13.14, so
  T = (194.8 − 200)/(13.14/√10) = −5.2/4.156 = −1.25. This
  does not fall in R.
  • H₀ is not rejected at α = 0.01
  • There is no strong evidence that the true mean is within the safety level

Testing a Population Proportion
H₀ : p = p₀ versus H₁ : p ≠ p₀, with n large




             Z = ( p̂ − p₀ ) / √( p₀q₀ / n ) where p̂ = X/n is the sample proportion and q₀ = 1 − p₀.
     For a large sample the sample proportion is approximately normally distributed. Under the null hypothesis the
   proportion has the specified value p₀, so the standardised statistic above has the N(0,1) distribution. Because the
   alternative is two-sided, the rejection region of a level-α test is R : |Z| ≥ z(α/2). The five steps are unchanged; only
                                                     the statistic differs.
TESTS FOR A POPULATION PROPORTION


Example: Families Below the Poverty Level
A census five years ago recorded 20%. A sample of 400 families now finds 70 below the level.




  H₀ : P = 0.20 VS H₁ : P ≠ 0.20
  At α = 0.05 the rejection region is R : |Z| ≥
  1.96
  p̂ = 70/400 = 0.175. The standard error is √(0.2 × 0.8 /
  400) = 0.020, so Z = (0.175 − 0.200)/0.020 = −1.25.
  • |−1.25| = 1.25 < 1.96, so H₀ is not rejected at α = 0.05
  • The data do not indicate that the percentage has changed
