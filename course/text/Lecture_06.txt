The Sampling Distribution

                Definition — The probability distribution of a statistic is called its sampling distribution


  1
  A sample is only a part of the population, the numerical value of a statistic cannot be expected to give us the exact
  value of the parameter.



  2
  The observed value of a statistic depends on the particular sample that happens to be selected.



  3
  There will be some variability in the value of statistic over different occasions of sampling. Therefore, it is
  considered to be a random variable

Q-Q plot

 DEFINITION
 A Q-Q plot (quantile-quantile plot) is a graphical tool
 used to compare two probability distributions—most
 commonly a set of sample data against a theoretical
 normal distribution.
 • X-Axis (Theoretical Quantiles): The expected values if your data
   followed the chosen reference distribution (like a standard normal
   distribution, N(0,1))
 • Y-Axis (Sample Quantiles): Your actual sorted data values.
 • Reference Line: A diagonal 45-degree line. If the data points fall
   neatly along this line, the two distributions match
