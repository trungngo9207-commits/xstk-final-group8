MATCHED PAIR COMPARISONS


F-Statistic


  F-test
  An F-test is a statistical test that compares variances. It
  is used to determine if the variances of two samples, or
  if the ratios of variances among multiple samples, are
  significantly different.
  Null Hypothesis (H₀): σ₁² = σ₂² (The population
  variances are equal).
  Alternative Hypothesis (H₁):
  • σ₁² ≠ σ₂² (Two-tailed)
  • σ₁² > σ₂² (Right-tailed)
  • σ₁² < σ₂² (Left-tailed)



          Foundational mathematical engine behind ANOVA (Analysis of Variance) and Multiple linear regression

ANOVA Is the Pooled t-Test for k Groups




                       MSW = SSW/(N − k) is the pooled variance s_p², extended to k groups.
                           With k = 2, the ANOVA F equals the square of the pooled t:
   ANOVA therefore carries the same assumptions as the pooled t-test: independent random samples, approximately
       normal populations, and a common σ. Here the three sample variances are equal, so the assumption is
     comfortable. When group variances differ strongly, the same warning as in the branch example applies, and a
                     version of ANOVA that does not pool — Welch's ANOVA — is used instead.

The Dummy Variable Trap


   With k categories, use k − 1 dummies. Adding a third dummy D_A makes D_A + D_B + D_C =
                   1 for every store — an exact copy of the intercept column.

     The model then has infinitely many equally good answers: any amount can be moved out of the intercept and
   added to all three dummies without changing a single prediction. The software cannot choose, and may not say so
                                                       clearly.




                        k categories → k − 1 dummies. The category left out is the reference group.
ANOVA AS A REGRESSION


Changing the Reference Group



  REFERENCE = A
  b₀ = 49, D_B = +7, D_C = +2. The coefficients answer: how do B and C compare with A?



  REFERENCE = C
  b₀ = 51, D_A = −2, D_B = +5. The coefficients answer: how do A and B compare with C?
  B versus C now has its own standard error and t.


  WHAT DOES NOT CHANGE
  Fitted values, residuals, SSR = 104, R² = 0.634, F = 7.8. The model is the same; only the question each coefficient
  answers is different.

Adjusted R²: A Price for Each Variable




  R² never falls when a variable is added — even a column of random numbers. Adjusted R² = 1
              − (1 − R²)(n − 1)/(n − k − 1) charges a price for each of the k predictors.
  Model (3): 1 − (1 − 0.914) × 11/8 = 0.882. Adjusted R² compares models of different size on the same data. It is not a
     test, and a high value does not make a model right: model (1) had R² = 0.63 and a biased layout coefficient.
