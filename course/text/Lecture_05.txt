RANDOM VARIABLES


Random variables: definition and classification



  DEFINITION
  A rule that assigns a number to each
  outcome
  A random variable (biến ngẫu nhiên) is a function
  mapping every outcome of an experiment to a number.
  It is the assignment rule, not the number itself.
  • Discrete: the values can be listed one by one
  • Continuous: between any two values a further value exists




                   The key to decide a variable is random or not is the “UNCERTAINTY” of the results

EXPECTATION AND VARIANCE


From empirical frequency to probability distribution




  CONSTRUCTION
  Count, then divide
  The probability mass function (hàm khối xác suất),
  written p(x), lists every value the variable can take
  together with the probability attached to each.
  • Step 1 — count the occurrences of each value
  • Step 2 — divide each count by the total
  • Two conditions: p(x) ≥ 0, and the values sum to 1

DISCRETE DISTRIBUTION


The Bernoulli Distribution




  ONE TRIAL, TWO OUTCOMES
  A single parameter p
  A Bernoulli random variable takes the value 1 with
  probability p and 0 with probability 1 − p
  • E(X) = p
  • Var(X) = p(1 − p)
  • An outcome that is neither rare nor near-certain carries the greatest
    uncertainty
DISCRETE DISTRIBUTION


The Binomial Distribution (Phân bố Nhị thức)
The number of successes in n independent Bernoulli trials




  DEFINITION
  A binomial random variable (biến nhị thức) counts the successes in n independent trials with constant probability
  p. E(X) = np and Var(X) = np(1 − p)


  FORMULA
  P(X = k) = C(n, k) · pᵏ · (1 − p)ⁿ⁻ᵏ
  In practice the probability is obtained from software: BINOM.DIST(k, n, p, FALSE) for an exact count.


  APPLICATION
  Number of defected products
  Conversion rate in E-commerce platform
  Medicine effectiveness
  Guessing answers on a multiple-choice test

Density is proportion per unit of the variable

probability density (mật độ xác suất), written f(x),

• A density is therefore not a probability, and f(x) may exceed 1

The Cumulative Distribution Function (CDF)




  ACCUMULATED AREA
  F(x) = P(X ≤ x)
  The cumulative distribution function (hàm phân phối
  tích lũy) records the area under the density to the left
  of x. It is non-decreasing, approaching 0 at the lower
  extreme and 1 at the upper.
  • P(X > c) = 1 − F(c)
  • P(a < X < b) = F(b) − F(a)
  • F is the function statistical software returns
