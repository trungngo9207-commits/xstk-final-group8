SKEWED Y: LOG MODELS


Log-linear model
ln(Y) = β₀ + β₁X₁ + … + βₖXₖ + ε



                                                              CONSEQUENCE
  MECHANISM
                                                              Coefficients become percentages
  Logarithms turn ratios into differences                     A one-unit increase in X changes Y by about 100·β
  ln(1.10 × Y) − ln(Y) = ln(1.10) ≈ 0.10. A constant          percent. For a dummy, the exact effect is (e^β − 1) × 100
  difference in ln(Y) is a constant percentage change in Y.   percent.
  Taking logs also pulls in the long right tail.              • Small β (below about 0.1): 100·β is a good approximation
                                                              • Large β or dummies: use (e^β − 1)




         Why might a 1-point higher score add a fixed percentage rather than a fixed number of dollars?
SKEWED Y: LOG MODELS


Why use log-linear model
ln(Y) = β₀ + β₁X₁ + … + βₖXₖ + ε




 Log-transformed dependent variable models
 A log-linear model is often used when the relationship
 between the variables is multiplicative rather than
 additive
 • Growth or Changes are Percentage-Based
    (Exponential)
 • Highly Skewed Data (Non-Normality)
 • Heteroskedasticity – Không đồng nhất phương sai
    (Unstable Variance)
 • Modeling "Elasticity" in Economics (Log-Log Variant)
SKEWED Y: LOG MODELS


Four functional forms


 Model                 Equation               Reading of β₁


 Linear                Y = β₀ + β₁X           X + 1 unit → Y changes by β₁ units


 Log-linear            ln(Y) = β₀ + β₁X       X + 1 unit → Y changes by about 100·β₁ %


 Linear-log            Y = β₀ + β₁ln(X)       X + 1 % → Y changes by about β₁/100 units


 Log-log               ln(Y) = β₀ + β₁ln(X)   X + 1 % → Y changes by about β₁ % (elasticity)


 Rule                  A log on one side      That side is read in percent

BINARY Y: PROBABILITY MODELS


Linear probability model (LPM)
OLS with a 0/1 dependent variable: P(Y=1) = β₀ + β₁X₁ + β₂X₂ + ...



                                                                     CONSEQUENCE
  MECHANISM
                                                                     β is a change in probability
  The mean of a 0/1 variable is a probability                        A one-unit increase in X changes P(Y = 1) by β,
  When Y takes only the values 0 and 1, E[Y | X] = P(Y = 1           measured in percentage points.
  | X). OLS on Y therefore estimates a probability as a              • Easy to estimate and read in Excel
  straight line in X.                                                • Fitted probabilities can fall below 0 or above 1
                                                                     • The effect of X is forced to be the same at every level
